# Inventario CLI BUHO

Inventario estatico de los Python de `scripts/` y `src/`, con los lanzadores raiz `main.py` y `run_hse06_nsc_dos.py` incluidos porque hoy tambien exponen comportamiento operativo. No se ejecutaron calculos ni imports de GPAW/torch/matgl para producirlo.

## Revision del plan

- Archivos inventariados: 186 (`scripts/`: 68, `src/`: 116, raiz: 2)
- Filas sin comando asignado: 0.
- Regla de agrupacion: dominio primero; los scripts historicos quedan como subcomandos del dominio y aceptaran passthrough de sus argumentos actuales cuando aun no exista una API nativa.
- Los comandos de ayuda y diagnostico deben ser ligeros: los imports cientificos se hacen dentro del callback que ejecuta calculos.
